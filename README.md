# LSILib

**LSILib** — это библиотека функциональных блоков (Function Blocks) для системы SCADA MasterSCADA, предназначенная для создания визуальных элементов управления промышленными устройствами и работы с данными.

## Описание

LSILib представляет собой декомпилированную библиотеку (.dll), разработанную для интеграции с системой автоматизации InSAT и MasterSCADA. Библиотека содержит готовые компоненты для построения HMI (Human-Machine Interface) интерфейсов промышленных систем управления.

## Основные компоненты

### 1. Управление устройствами (FB.Device)
- **ValveBaseControl** — базовое управление клапанами
- **SlideValveBaseControl** — управление шиберными клапанами  
- **PumpBaseControl** — управление насосами
- **ControlBase** — базовый класс для всех устройств управления

Все элементы управления поддерживают:
- Визуальное отображение состояния устройств
- Интеграцию с OPC серверами
- Настраиваемый интерфейс пользователя

### 2. Медленные клапаны (FB.SlowValve)
- **SlowValve** — функциональный блок для управления медленными клапанами
- **ControlBase** — базовые элементы управления
- **ControlWindow** — окно управления с расширенным функционалом

### 3. Табличные данные (FB.Table)
- **Table** (LSI_Table) — основной функциональный блок для работы с табличными данными
- **TableControl** — визуальный элемент управления таблицами

#### Возможности табличного компонента:
- **Протоколы связи**: Modbus, SLMP (частично реализован)
- **Типы данных**: Float, Int, Bool
- **Функции**: 
  - Загрузка/сохранение рецептов из файлов
  - Редактирование данных в runtime
  - Сетевая передача данных по TCP/IP
  - XML конфигурация структуры таблиц

## Технические характеристики

- **Платформа**: .NET Framework
- **Язык**: C#
- **Версия**: 1.0.0.0
- **Совместимость**: MasterSCADA, InSAT OPC
- **Поддерживаемые протоколы**: Modbus TCP/IP, SLMP

## Архитектура

Библиотека построена на основе:
- **VisualFBBase** — базовый класс для визуальных функциональных блоков
- **VisualControlBase** — базовый класс для элементов управления
- **COM-интерфейсы** — для интеграции с SCADA системами
- **OPC подключения** — для связи с промышленными контроллерами

## Использование

Библиотека предназначена для использования в составе SCADA проектов:

1. **Добавление в проект**: Подключить LSILib.dll к проекту MasterSCADA
2. **Настройка связи**: Конфигурировать OPC подключения
3. **Размещение элементов**: Добавить функциональные блоки на HMI формы
4. **Конфигурация**: Настроить параметры устройств и протоколов связи

## Системные требования

- Windows (32/64-bit)
- MasterSCADA установленная в `C:\Program Files (x86)\MPSSoft\MasterSCADA\`
- .NET Framework
- OPC сервер для связи с контроллерами

## Примечание

Данная версия библиотеки является декомпилированной (создана с помощью JetBrains decompiler) и представляет собой legacy код, разработанный в 2019 году для промышленной автоматизации.
